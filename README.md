# 燕云十六声 / 연운십육성 (Where Winds Meet)
## 인터랙티브 공식 소개 웹사이트 & 무협 체험관 / 交互式官方介绍网站与武侠沉浸体验馆

---

### 1. 작품 개요 및 목적 / 作品用途与创作目的

* **작품 명칭 / 作品名称**: 연운십육성 인터랙티브 웹 체험관 / 《燕云十六声》交互式双语体验馆
* **작품 유형 / 作品类型**: 🌐 웹사이트 (홈페이지 / 网站)
* **대상 게임 / 主题游戏**: 《燕云十六声》（Where Winds Meet / Everstone Studio 제작 오픈월드 무협 RPG）
* **기획 목적 / 创作目的**:
  * **한국어**: 게이머가 가장 사랑하는 정통 무협 게임 《연운십육성(燕云十六声)》의 웅장한 오대십국 역사적 세계관, 심도 있는 무공 및 점혈 시스템, 18반 병기와 문파, 오픈월드 지도를 상세하고 매력적인 비주얼과 인터랙티브 기술로 구현하여 사용자가 웹상에서 직접 강호를 체험할 수 있도록 제작했습니다.
  * **中文**: 为喜爱开放世界正统武侠大作《燕云十六声》的玩家打造集视、听、交互于一体的高品质网页体验馆。通过五代十国历史长卷、点穴奇术演练、神兵门派鉴赏、互动全景地图及视听画廊，让用户直观领略“风吹过的大地，皆是江湖”之武侠美学。
* **★ 필수 조건 완벽 충족 / ★ 严格达成必须要求**:
  * 웹사이트의 모든 타이틀, 메뉴, 버튼, 설명, 안내 문구, 결과 메시지 등 일체의 텍스트가 **한국어·중국어 병기(韩中双语并列)**로 구성되어 있습니다.

### 2. 주요 기능 및 구성 / 主要功能与模块架构

| 모듈 명칭 / 模块名称 | 주요 기능 / 主要功能 | 인터랙티브 요소 / 交互亮点 |
| :--- | :--- | :--- |
| **01. 메인 히어로 / 封面盛景** | 웅장한 타이틀, 시적 슬로건, 핵심 특징 수치 안내 | 캔버스 기반 흩날리는 복숭아꽃잎 및 금빛 수묵 파티클 (`particle-canvas`), Web Audio API 고쟁 5음계 음향 토글 |
| **02. 세계관 소개 / 世界观史诗** | 오대십국 말기, 연운 16주 할양의 역사적 비극과 배경 서사 | 마우스 호버 시 붉은 인장 효과 및 3대 역사 기록 카드 3D 틸트 연출 |
| **03. 점혈 & 무공 시뮬레이터 / 点穴与奇术模拟器** | 인체 경락도(백회, 단중, 단전, 합곡, 족삼리) 및 4대 절기 무공(태극, 경공, 사자후, 만검) | 혈자리 클릭 시 실제 점혈 파열음 및 시각적 기혈 플래시 발동, 무공 선택 시 동적 무공 연무 연출 |
| **04. 병기보 & 문파 시스템 / 兵器谱与门派势力** | 6종 핵심 무기(검, 창, 부채, 우산, 쌍도, 활)와 4대 문파(신기영, 취후문, 삼류문, 무문무파) | 무기 탭 전환 시 발도음(拔刀音) 재생, 4대 능력치 게이지(사거리, 속도, 위력, 난이도) 애니메이션, 칼날 시험 버튼 |
| **05. 인터랙티브 강호 전도 / 交互式江湖地图** | 청하, 개봉 황성, 연운 16주, 맹진 귀시, 창산 설봉 등 5대 명소 | 고지도 위 마커 클릭 시 풍경음 재생, 기후·위험도·지역 주요 기연(3종) 동적 렌더링 및 답파 출발 알림 |
| **06. 비경 갤러리 & 라이트박스 / 视觉画廊与全屏赏析** | 전투 액션, 강호 절경, 협객 영웅 카테고리별 고화질 화랑 | 태그 필터링, 이미지 호버 확대, 클릭 시 전체화면 라이트박스 모달(이전/다음 탐색 지원) |
| **07. 강호 성향 테스트 / 宿命侠客测验** | 4단계 상황 판단 심리 퀴즈를 통한 자신의 강호 운명 진단 | 퀴즈 진행도 바, 4대 협객 유형(일검서천 검객, 호가음월 취선, 만부부당 장수, 천인무위 은사) 도출 및 명첩 클립보드 복사 |
| **08. 웹 오디오 사운드 엔진 / 纯Web Audio音效** | 외부 mp3 파일 없이 순수 Web Audio API로 합성된 무협 사운드 | 칠현금 5음계(궁·상·각·치·우), 메탈릭 발도음, 청아한 점혈음, 기공 방출 저음 합성 |

### 3. 디렉터리 구조 / 目录结构

```
d:\Git\ossw2\
│
├── index.html          # 메인 HTML 웹페이지 (한국어·중국어 완전 병기)
├── README.md           # 본 프로젝트 설명서 (한중 쌍어 문서)
│
├── css/
│   └── style.css       # 동양 수묵 테마 CSS (다크 골드 & 주홍빛, 글래스모피즘, 반응형)
│
└── js/
    ├── audio.js        # Web Audio API 기반 오디오 엔진 (5음계, 발도, 점혈, 기공음)
    ├── particles.js    # Canvas 흩날리는 꽃잎 및 잉크 입자 애니메이션
    ├── skills.js       # 점혈 경락도 및 무공 절학 시뮬레이터 인터랙션
    ├── weapons.js      # (main.js 통합) 병기보 스탯 및 문파 시스템
    ├── map.js          # 인터랙티브 강호 지도 마커 및 지역 상세 정보
    ├── gallery.js      # 갤러리 카테고리 필터 및 전체화면 라이트박스 모달
    ├── quiz.js         # 강호 성향 심리 퀴즈 및 명첩 복사 기능
    └── main.js         # 전역 이벤트 조율, 네비게이션 스크롤, 효과음 바인딩
```

### 4. 실행 및 테스트 방법 / 运行与使用指南

1. **로컬 브라우저에서 직접 열기 / 直接在浏览器中打开**:
   * 본 프로젝트는 순수 표준 웹 기술(HTML5, CSS3, Vanilla JS)로 제작되어 별도의 서버나 패키지 설치(`npm`, `python` 등) 없이 바로 실행 가능합니다.
   * `d:\Git\ossw2\index.html` 파일을 더블 클릭하거나 선호하는 웹 브라우저(Chrome, Edge, Whale 등)로 드래그 앤 드롭하여 바로 열 수 있습니다.
   * PowerShell 명령어로 즉시 열기:
     ```powershell
     Start-Process "d:\Git\ossw2\index.html"
     ```

2. **인터랙티브 기능 사용 팁 / 交互体验建议**:
   * 🎵 **사운드 체험**: 상단 우측의 `🎵 음향 켜짐 / 音效开启` 버튼이 활성화된 상태에서 버튼이나 탭, 혈자리 핀을 클릭하면 실시간 합성되는 무협 음향을 들을 수 있습니다.
   * ⚡ **점혈 시뮬레이터**: 경락도의 혈자리(붉은 펄스 핀)를 클릭하고 `⚡ 혈도 자극 발동 / 激发经络反应` 버튼을 눌러 기혈 폭발 시각 효과를 체험해 보세요.
   * 🗡️ **병기 시험**: 상단 6종 무기 탭을 눌러 무기를 변경하고 `🗡️ 칼날 휘두르기 / 拔刀试锋` 버튼을 눌러보세요.
   * 📜 **성향 퀴즈**: 4가지 질문에 직관적으로 답한 뒤 당신의 강호 운명을 확인하고 `📜 강호 명첩 복사 / 复制侠客身份`를 통해 결과를 공유해 보세요.
